# 同济大学国豪书院 · 工科大一笔记

同济大学国豪书院工科大一课程的手写笔记整理，以 PDF 形式分享，供复习与参考。

## 内容一览

| 课程 | 页数 | 文件 | 概要 |
| --- | --- | --- | --- |
| 工科数学分析（上）· 定积分的应用 | 1 | [工科数学分析上定积分的应用.pdf](./工科数学分析上定积分的应用.pdf) | 平面图形面积、旋转体体积、曲线弧长、曲率、旋转曲面面积等公式与用法汇总 |
| 工科数学分析（下） | 50 | [黑猫的工科数学分析下笔记.pdf](./黑猫的工科数学分析下笔记.pdf) | 数项级数、函数列与函数项级数、幂级数、傅里叶级数、多元函数极限与连续、多元函数微分学、隐函数定理及其应用、曲线积分、重积分、曲面积分 |
| 大学物理（荣） | 8 | [黑猫的大学物理（荣）笔记.pdf](./黑猫的大学物理（荣）笔记.pdf) | 课程要点手写整理 |
| 普通化学（荣） | 10 | [黑猫的普通化学（荣）笔记.pdf](./黑猫的普通化学（荣）笔记.pdf) | 课程要点手写整理 |

> 「（荣）」指授课教师。数学分析（下）共 50 页，已按章节顺序编排（数项级数 → 函数列与函数项级数 → 幂级数 → 傅里叶级数 → 多元函数 → 曲线积分 → 重积分 → 曲面积分）。
